# 데이터 사전 (Data Dictionary)

원천 데이터: `data/customers_dashboard.parquet` (고객 단위 1행 = 1명).

## 원본 컬럼

| 컬럼명 | 타입 | 설명 |
|---|---|---|
| customer_id | string | 고객 고유 식별자(해시값). 고객 응대 페이지 검색 키로 사용. |
| age | int | 고객 나이. |
| club_member_status | string | 클럽 멤버십 상태. `ACTIVE`(활성), `PRE-CREATE`(가입 전 단계), `LEFT CLUB`(탈퇴). |
| fashion_news_frequency | string | 패션 뉴스레터 수신 빈도. `Regularly`(정기 수신), `Monthly`(월간 수신), `NONE`(미수신). 값이 결측이면 "정보 없음"으로 표시. |
| days_since_last_purchase | int | 마지막 구매 이후 경과일 (Recency 원값). |
| purchase_count | int | 누적 총 구매 횟수 (Frequency 원값). |
| total_spent | float | 누적 총 구매 금액 (Monetary 원값). |

## 파생 컬럼 (assign_segments 실행 후 추가됨)

| 컬럼명 | 설명 |
|---|---|
| r_score | Recency 4분위 점수 (1~4, 4가 가장 최근). |
| f_score | Frequency 4분위 점수 (1~4, 4가 가장 빈번). |
| m_score | Monetary 4분위 점수 (1~4, 4가 가장 고액). |
| segment | RFM 규칙으로 배정된 최종 세그먼트명(VIP/이탈위험/충성/신규/일반). |

## 화면별 매핑

- **고객 응대 페이지**: customer_id로 조회 → age, club_member_status, fashion_news_frequency, days_since_last_purchase, purchase_count, total_spent, segment를 프로필 카드로 표시.
- **경영진 대시보드**: 전체 고객에 대해 total_spent 집계(KPI), segment 분포, 세그먼트별 RFM 원값 평균.

## 뱃지 색상 매핑 (UI 참고용)

- 클럽 상태: ACTIVE=녹색, PRE-CREATE=파랑, LEFT CLUB=빨강, 결측=회색.
- 뉴스 수신: 정기 수신=녹색, 월간 수신=파랑, 미수신=빨강, 정보 없음=회색.
- 세그먼트: VIP=보라, 충성=녹색, 신규=파랑, 이탈위험=빨강, 일반=회색.

## 주의사항

- 이 데이터셋은 거래 로그가 아니라 고객 단위로 이미 집계된 스냅샷이다. 특정 일자/기간 필터링(예: "지난달 매출")은 현재 컬럼만으로는 불가능하다.
- age, total_spent 등에는 결측치가 존재할 수 있으며 일부 화면(뱃지)은 결측을 "정보 없음"으로 처리한다.
